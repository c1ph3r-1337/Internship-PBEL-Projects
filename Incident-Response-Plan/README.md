# Cybersecurity Policies and Incident Response Plan for a Small Business

This internship project presents a practical cybersecurity policy suite and incident response plan for **BrightPath Services**, a fictional 30-person small business. It is designed to help small organizations prevent common cyber threats, respond effectively to incidents, and restore business operations safely.

## Project Highlights

- Based on the **NIST Cybersecurity Framework 2.0**: Govern, Identify, Protect, Detect, Respond, and Recover
- Includes policies for access control, passwords and MFA, patching, backups, data protection, phishing, remote access, logging, and vendor security
- Defines incident-response roles, severity levels, escalation procedures, evidence handling, communication, and recovery steps
- Provides practical playbooks for phishing/BEC, ransomware, lost devices, cloud data exposure, and website outages
- Includes a 90-day implementation roadmap, security metrics, checklists, and reusable incident-response templates
